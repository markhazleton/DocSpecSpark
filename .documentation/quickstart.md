# DocSpark Quickstart

DocSpark installs a structured document AI workflow derived from DevSpark into a target repository.

1. Run `docspark init my-docs-repo` or use one of the quickstart prompts in `quickstart/`.
2. Review `.documentation/memory/constitution.md` and make it specific to the repo.
3. Start with `/docspark.specify` for a new document initiative or `/docspark.quickfix` for a narrow correction.
4. Keep team overrides in `.documentation/commands/` and personal overrides in `.documentation/{git-user}/commands/`.
