# DocSpark Constitution

## Project
DocSpark

## Purpose
Keep documentation operational, reviewable, and trustworthy with a document AI workflow derived from DevSpark.

## Core Principles
- Prefer a single source of truth.
- Make ownership and review cadence explicit.
- Treat ambiguity as a defect.
- Archive stale work instead of leaving it in the active path.
- Optimize for the real audience, not the author.
