# DocSpark Examples

This folder contains reference repositories that show what a project looks like after DocSpark is installed.

The goal is the same as DevSpark's `examples/` area: make the installed shape concrete so users can see the separation between framework-managed assets and user-owned work.

## Included Example

- `policy-portal/` — a minimal documentation repository for policies, standards, and procedures managed with DocSpark

## What These Examples Demonstrate

1. `.docspark/` vs `.documentation/` separation
2. Constitution governance in `.documentation/memory/constitution.md`
3. Multi-user command resolution with team and personal override paths
4. GitHub Copilot shim files under `.github/agents/` and `.github/prompts/`
5. Installed VERSION stamp and stock command inventory

Use these folders as reference snapshots, not as live framework sources.
