# {{COMPANY_NAME}} Production Control Procedure

## Purpose

This procedure defines work order release, material control, traceability, and shop-floor execution requirements.

## Procedure Outline

1. Work order, BOM, and routing release controls.
2. Material staging, identification, and traceability rules.
3. In-process checks and production status tracking.
4. Handling of rework, holds, and nonconforming product.
5. Production record retention and handoff expectations.
