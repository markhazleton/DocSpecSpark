# {{COMPANY_NAME}} Incident Response Plan

## Purpose

This plan defines how {{COMPANY_NAME}} detects, contains, investigates, and recovers from cybersecurity incidents.

## Response Stages

1. Detection, triage, and severity classification.
2. Containment, evidence preservation, and escalation.
3. Recovery, stakeholder communications, and legal review.
4. Root cause analysis and corrective actions.
5. Post-incident review and record retention.
